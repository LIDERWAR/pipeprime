# PipePrime — Оптовые поставки полимерных труб PE-RT тип II и ППУ

Официальный дистрибьютор современных полимерных трубопроводных систем **PE-RT тип II**, предизолированных труб в пенополиуретановой изоляции (**ППУ/ПЭ** и **ППУ/ОЦ**), фитингов и комплектующих для систем теплоснабжения, отопления и горячего водоснабжения (ГВС).

---

## 📌 О проекте

Веб-платформа **PipePrime** разработана для B2B-клиентов: проектных институтов, генподрядчиков, монтажных организаций и девелоперов.

### Основные разделы:
- **Главная (`index.html`)** — презентация преимуществ PE-RT тип II перед сталью и сшитым полиэтиленом (PEX), продуктовая линейка, интерактивный экспресс-калькулятор, презентация Альбома технических решений (АТР 2026), корзина/спецификация.
- **Каталог (`catalog.html`)** — интерактивный каталог с фильтрацией по категориям (трубы без изоляции, ППУ/ПЭ, ППУ/ОЦ, фитинги, КЗС), поиском и мгновенным добавлением в заказ.
- **Инженерный калькулятор (`calculator.html`)** — точный расчет метража, хлыстов по 12 м, веса партии, комплектов заделки стыков (КЗС) и подбор грузового транспорта (еврофуры 13.6 м).
- **Проектирование и АТР (`engineering.html`)** — нормативная база (ГОСТ 32415-2013, ГОСТ Р 56730-2015, СП 315.1325800.2017), описание разделов АТР 2026 и форма запроса технической документации.
- **Оплата и доставка (`delivery.html`)** — условия для B2B-заказчиков, отсрочка платежа до 60 дней, факторинг, правила транспортировки труб и фасонины.
- **О компании (`about.html`)** — ценности, складские мощности, география поставок и модель работы без наценок.
- **Контакты (`contacts.html`)** — реквизиты, форма отправки проектной ведомости/спецификации, интерактивная карта складов и филиалов.

## 🛠 Технологический стек

- **HTML5** (семантическая разметка, Open Graph, microdata)
- **Vanilla CSS3** (собственная дизайн-система с CSS Custom Properties, темная эстетика с акцентными цветами, адаптивная верстка без внешних тяжелых фреймворков)
- **Vanilla JavaScript (ES6+)**:
  - Модульный каталог с локальным стейтом корзины (`catalog-data.js`, `catalog.js`)
  - Инженерный калькулятор логистики и материалов (`calculator.js`)
  - Drawer-панель спецификации, модальные окна, мобильное меню (`app.js`)
- **Шрифты**: Inter, JetBrains Mono (Google Fonts)

## 🚀 Локальный запуск

Проект является статическим веб-приложением и не требует сборки. Для запуска достаточно открыть `index.html` в любом современном браузере или использовать любой локальный HTTP-сервер:

```bash
# С использованием Python
python -m http.server 8000

# С использованием Node.js (npx serve)
npx serve .

# Или расширение Live Server в VS Code
```
