# PipePrime — Оптовые поставки полимерных труб PE-RT тип II и ППУ

Официальный дистрибьютор современных полимерных трубопроводных систем **PE-RT тип II**, предизолированных труб в пенополиуретановой изоляции (**ППУ/ПЭ** и **ППУ/ОЦ**), фитингов и комплектующих для систем теплоснабжения, отопления и горячего водоснабжения (ГВС).

---

## 📌 О проекте

Веб-платформа **PipePrime** разработана для B2B-клиентов: проектных институтов, генподрядчиков, монтажных организаций и девелоперов.

### Основные разделы:
- **Главная (`index.html`)** — презентация преимуществ PE-RT тип II перед сталью и сшитым полиэтиленом (PEX), продуктовая линейка, интерактивный экспресс-калькулятор, презентация Альбома технических решений (АТР 2026), корзина/спецификация.
- **Каталог (`catalog.html`)** — интерактивный каталог с фильтрацией по категориям (трубы без изоляции, ППУ/ПЭ, ППУ/ОЦ, фитинги, КЗС), поиском и мгновенным добавлением в заказ.
- **Инженерный калькулятор (`calculator.html`)** — точный расчет метража, хлыстов по 12 м, веса партии, комплектов заделки стыков (КЗС), подбор транспорта (еврофуры 13.6 м) и мгновенная генерация брендированного PDF коммерческого предложения.
- **Проектирование и АТР (`engineering.html`)** — нормативная база (ГОСТ 32415-2013, ГОСТ Р 56730-2015, СП 315.1325800.2017), описание разделов АТР 2026 и защищенный запрос корпоративного доступа к документации.
- **Оплата и доставка (`delivery.html`)** — условия для B2B-заказчиков, отсрочка платежа до 60 дней, факторинг, правила транспортировки труб и фасонины.
- **О компании (`about.html`)** — ценности, складские мощности, география поставок и модель работы без наценок.
- **Контакты (`contacts.html`)** — реквизиты, форма отправки проектной ведомости/сметы (файлы до 50 МБ), интерактивная карта складов и филиалов.

## 🛠 Технологический стек

### Frontend
- **HTML5** (семантическая разметка, Open Graph, microdata)
- **Vanilla CSS3** (собственная дизайн-система с CSS Custom Properties, темная промышленная эстетика, сетка `--container-max: 1640px`)
- **Vanilla JavaScript (ES6+)**:
  - Модульный каталог со стейтом спецификации (`catalog-data.js`, `catalog.js`)
  - Инженерный калькулятор логистики и материалов с генератором PDF (`calculator.js`)
  - Drawer-панель спецификации, асинхронные формы, модальные окна (`app.js`)
- **Шрифты**: Outfit, Inter, JetBrains Mono (Google Fonts)

### Backend (Python FastAPI)
- **FastAPI** + **Uvicorn** — высокопроизводительный асинхронный REST API.
- **Pydantic v2** — строгая валидация входящих схем, ИНН организаций и спецификаций.
- **SQLite** — встроенное легковесное хранилище заявок и токенов доступа.
- **ReportLab** — программная генерация официальных технико-коммерческих предложений (PDF) со штампом PipePrime и расчетом логистики.
- **Telegram Bot API (httpx)** — асинхронные уведомления в закрытый чат инженеров PipePrime о новых спецификациях, сметах и запросах АТР.
- **Защита IP (АТР 2026)** — защищенное изолированное хранение PDF и выдача по одноразовым временным токенам (TTL 24ч).

## 🔌 Архитектура API

| Метод | Эндпоинт | Описание |
| :--- | :--- | :--- |
| `GET` | `/api/health` | Проверка статуса сервера |
| `POST` | `/api/leads/specification` | Прием спецификации из Drawer-корзины с составом заказа |
| `POST` | `/api/leads/estimate` | Загрузка файлов проектных смет (PDF, DWG, XLSX до 50 МБ) |
| `POST` | `/api/leads/callback` | Экспресс-заявка на звонок / консультацию инженера |
| `POST` | `/api/atr/request` | Корпоративный запрос АТР 2026 (генерация защищенного токена) |
| `GET` | `/api/atr/download/{token}` | Скачивание АТР 2026 по временному токену доступа |
| `POST` | `/api/calculator/generate-pdf` | Генерация официального КП в формате PDF на лету |
| `GET` | `/docs` | Интерактивная документация Swagger UI |

## 🚀 Запуск проекта

### Вариант 1. Запуск через Docker Compose (Рекомендуется для Production)
```bash
# 1. Запустить контейнер
docker compose up -d --build

# 2. Проверить статус
curl http://localhost:8000/api/health
```

### Вариант 2. Локальный запуск на Python
```bash
# 1. Установка зависимостей
python -m pip install -r server/requirements.txt

# 2. Настройка переменных окружения (опционально)
# Скопируйте server/.env.example в server/.env и укажите токен Telegram-бота

# 3. Запуск сервера (UI + API)
python -m uvicorn server.main:app --host 0.0.0.0 --port 8000 --reload
```

После запуска:
- **Веб-платформа:** `http://localhost:8000`
- **Интерактивная документация API (Swagger):** `http://localhost:8000/docs`
- **Альтернативная документация (ReDoc):** `http://localhost:8000/redoc`
